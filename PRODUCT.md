# Stack Theory

## Register
brand

## Users
College students building Python agents, including people unable to attend in-person hackathons; prospective compute and event sponsors. The existing application supports teams, submissions, isolated execution, events and retrospective replays.

## Product Purpose
Make a student bot competition accessible online. Students supply strategy code, the organizer supplies initial engine compute, and sponsors can support future events. Visitors should understand the challenge and enter the working arena.

## Brand Personality
Competitive, tactile, audacious. The current user direction explicitly rejects generic AI landing-page styling and requests a striking 3D experience with only Arena, Sponsors and Contact as primary destinations.

## Anti-references
The previous cobalt dashboard hero, repeated rounded cards, decorative status pills, fictional traction, generic feature grids and broad navigation. Avoid casino profit promises: this is a code competition with simulated chips.

## Design Principles
1. The table is the identity: a dimensional, interactive physical scene.
2. Three clear destinations; tools live inside the arena.
3. Show actual functions and results, never invented sponsors or participants.
4. Put strong typography and precise composition before ornament.
5. Keep the original account, team, sandbox, competition and replay capabilities accessible.

## Accessibility & Inclusion
Preserve keyboard controls, readable contrast, reduced-motion behavior and a static fallback when WebGL is unavailable. The existing responsive application and user requests require both phone and large-monitor layouts.
