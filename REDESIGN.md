# Redesign brief

Authorized by the user's October 28 request to redo the whole aesthetic autonomously, use Hyde GLM coding agents and a visual judge, research 3D sites, and reduce navigation to Arena / Sponsors / Contact.

Physical scene: a student encounters a sculptural poker table in a brightly lit experimental game exhibition, with the tension of an oversized red competition poster behind it. Warm porcelain background, dense red display typography, red felt, black lacquer, ivory playing cards and silver chips. No blue SaaS panels.

Typography: Barlow Condensed heavy display, Barlow body, selected from Google Fonts' real catalog. Display scale 96–180px on desktop, 62–94px mobile. Compact navigation and unboxed text.

Hero: CAN YOUR AI / GAMBLE SMART? with a real-time three-dimensional poker table and hovering/dealing cards. Pointer movement changes the view gently; a Deal control visibly animates cards. Reduced motion freezes passive movement. Real competition CTA enters the existing workshop flow. Desktop composition fills the width; mobile becomes a deliberate poster and table stack.

Navigation: exactly Arena, Sponsors, Contact. Brand points home. Arena tools are contextual below the hero or on internal tool routes, never additional global destinations.

Research: Lusion https://lusion.co uses scale, material and interactive scenes as identity; Igloo https://www.igloo.inc treats 3D as a navigable world; Bruno Simon https://bruno-simon.com makes an immediately understandable interaction the experience. Adopt the principles, not their assets or layouts.

Image probe skipped: the intended artifact is live procedural 3D geometry, reviewed directly in the browser at phone and desktop sizes. No generated static mock will replace the real scene.
