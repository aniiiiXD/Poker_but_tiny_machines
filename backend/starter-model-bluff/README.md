# Bluff model starter (Stack Theory Bluff v1)

A bounded multi-file project template for the model track: `agent.py` plus a
local `weights.json` artifact. The runtime provides Python 3.12 and NumPy;
no network, no GPU. Package the folder as a ZIP (with `agent.py` at the
root) and upload it in the Workshop with the Bluff game selected.

Replace the hand-crafted features and weights with your own trained model —
training happens on your machine; only the inference artifact is submitted.
