# Hyde scene provenance

The procedural Three.js scene was generated by `hyde/glm-5.3-flash` via Hyde Inference's chat completions API. The first request exhausted 16,000 completion tokens in reasoning without returning code. A second request with low reasoning effort returned the component and stylesheet (6,410 completion tokens; 229 prompt tokens).

The generated code was reviewed and edited locally: removed unrelated invented salon copy, corrected card material face placement, replaced its page layout with a transparent embedded scene, and made the animation loop actually stop offscreen. TypeScript compilation passes. Subsequent Hyde GLM refinement supplied striped chip texture code and material/layout guidance. Integration then refined camera fit, raised card orientation, mobile controls, reduced-motion handling, and the feathered contact shadow. Desktop and mobile visual verification is complete; Astra approved the final rendered artifacts.
